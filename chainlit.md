# AI Document Analyst Pro

Ask questions about your documents (PDF, DOCX, PPTX, XLSX, CSV, TXT, MD, JSON).

- **Upload**: drag a file into the chat to process it.
- **Select**: use the settings (gear) icon to choose which documents to chat with.
- **Manage**: type `/documents` to list or delete processed documents.

Powered by Groq (`openai/gpt-oss-20b`), LangChain, ChromaDB, and PostgreSQL.
